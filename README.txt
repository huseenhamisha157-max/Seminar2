Seminar 2 - Enhanced sorting (Variant 18)

1. Откройте Seminar2.sln в Visual Studio 2022.
2. Сборка -> Пересобрать решение (интернет не нужен, Google Test лежит в enhanced_sorting_tests/googletest).
3. Тест -> Обозреватель тестов -> Выполнить все.

enhanced_sorting - статическая библиотека: binary_insertion_sort, shaker_sort (шаблоны).
enhanced_sorting_tests - Google Test, tests/test_binary_insertion_sort.cpp и tests/test_shaker_sort.cpp.
